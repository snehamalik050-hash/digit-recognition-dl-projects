# 🔢 Handwritten Digit Recognition using CNN

## 📖 Project Overview
This project uses **Convolutional Neural Networks (CNNs)** to classify handwritten digits (0–9) from the MNIST dataset.  
It demonstrates how deep learning can be applied to image recognition tasks.

---

## ⚙️ Methodology
1. Dataset: MNIST (70,000 grayscale images of digits).  
2. Preprocessing: Normalize pixel values, reshape to 28×28×1.  
3. Model: CNN with Conv2D, MaxPooling, Dense layers.  
4. Training: Adam optimizer, categorical cross‑entropy loss, 5 epochs.  
5. Evaluation: Accuracy on test set.  
6. Output: Predicts digit from input image.
---

## 📝 Conclusion
This project demonstrates how deep learning can accurately recognize handwritten digits using CNNs.  
It highlights the strength of convolutional architectures in image classification tasks.  
Future scope: extend the model to letters, symbols, or real‑world handwriting recognition.
